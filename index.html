Internship · Completed Oct 2026

Intern — BFS, Temenos Core Banking Technology
Aug – Oct 2026 · Karachi · On-site

Three months inside one of Pakistan's largest software companies, in the practice that implements Temenos core banking for banks across the region — hands-on with Transact (T24): maker-checker authorisation, Enquiries, Routines and Local Reference Tables, and what it takes to extend a core system without destabilising it.

  • Maker–checker, for realYou cannot approve your own transaction. An inputter enters it, a separate authoriser releases it. Obvious once you see it; not something I would have designed on my own.
  • Extending a core without touching itEnquiries, Routines and Local Reference Tables are how you add to T24 and still take the next upgrade.
  • Model Bank sessionsHands-on with how a bank's day is actually modelled, instead of an API and a Postman tab.
  • Software that cannot go downIt changed how I design anything meant to run for years, not just work in a demo.
